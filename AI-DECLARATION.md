## Notes

- **Design (pair):** The human developer defines the project requirements, FFXIV game mechanics, and UI/UX goals. The AI suggests technical architecture and code structure.
- **Implementation & Testing (auto):** The AI operates as an autonomous agent within the developer's local environment, writing the C# code, implementing UI features via ImGui, and generating/running xUnit tests directly in the terminal until they pass.
- **Documentation (auto):** Changelogs, pull request descriptions, and in-game tutorial texts are generated by the AI based on the commit history and implementation context.
- **Review (pair):** The human developer performs all in-game manual testing using Dalamud (since the AI cannot run the game client), providing screenshots, feedback, and logs back to the AI for iterative bug fixing.
- **Deployment (hint):** The human developer manages GitHub workflows and release triggers, while the AI provides YAML configurations when needed.
